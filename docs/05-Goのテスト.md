# Section 5: Go — テストを書く

> 📖 **詰まったら**：各Stepの答え（コード・コマンド）はこのファイル末尾の「付録: 各Stepの答え」にあります。まず自分で書いてから見ましょう。

## 1. 目的と完成の定義

**目的**: Goの標準テスト機能で、仕様どおりに動くことを自動で確認できるようにする。

**完成の定義**:
- [ ] `model` `store` `handler` それぞれにテストがある
- [ ] `go test ./...` がすべて成功する
- [ ] api-spec.md の「テスト観点」の異常系・境界値をカバーしている
- [ ] カバレッジを確認した（`go test -cover ./...`）
- [ ] テストをコミットした（`test:`）

## 2. 用語解説

| 用語 | 意味 |
|------|------|
| 単体テスト | 関数/型など小さな単位のテスト |
| テーブル駆動テスト | 入力と期待値を表にして、ループで回す書き方（Goの定番） |
| `httptest` | HTTPハンドラーを、サーバーを起動せずにテストする標準パッケージ |
| サブテスト | `t.Run("名前", ...)` で分ける単位 |
| カバレッジ | テストが通ったコードの割合 |
| レースデテクタ | 並行処理のバグ検出 (`-race`) |

## 3. 手順（コミット単位）

### Step 1: ブランチとAIへのテスト観点出し
```
git switch -c feat/05-tests
```

出力を `docs/test-plan.md` にし、レビューしてコミット。
`docs: add test plan`

### Step 2: modelのテスト（コミット）
ファイル: `internal/model/todo_test.go`

テーブル駆動の例（構造のみ）:
```go
tests := []struct {
    name    string
    input   string
    wantErr bool
}{
    {"通常", "牛乳を買う", false},
    {"空", "", true},
    {"空白のみ", "   ", true},
    {"100文字", strings.Repeat("あ", 100), false},
    {"101文字", strings.Repeat("あ", 101), true},
}
for _, tt := range tests {
    t.Run(tt.name, func(t *testing.T) { /* 実行して比較 */ })
}
```
ポイント: 日本語100文字（バイトではなく文字数）を必ず含める。

### Step 3: storeのテスト（コミット）
ファイル: `internal/store/memory_test.go`
- 追加 → 取得できる、一覧が新しい順
- 存在しないIDで `ErrNotFound`
- 更新で `UpdatedAt` が進む
- 並行追加（ゴルーチンから多数追加）して `go test -race`

### Step 4: handlerのテスト（コミット）
ファイル: `internal/handler/todo_test.go`

流れ:
1. メモリstoreでhandlerを組み立てる
2. `httptest.NewRequest` でリクエストを作る
3. `httptest.NewRecorder` でレスポンスを受ける
4. ステータスコードとJSONを検証する

最低限カバーする:
- POST 正常(201) / 空タイトル(400) / 壊れたJSON(400)
- GET一覧 0件で `[]`
- GET/PATCH/DELETE で存在しないID(404)、IDが文字列(400)
- PATCH `{}`(400)

### Step 5: 実行
```
go test ./...
go test -race ./...
go test -cover ./...
go test -coverprofile=cover.out ./... && go tool cover -html=cover.out
```
`cover.out` は `.gitignore` に入れる（`*.out` で対応済みか確認）。

### Step 6: バグが見つかったら
テストで見つけたバグは、**まず再現するテストを書く → 修正する**。コミットは分ける。
```
test: add failing test for PATCH with empty body
fix: reject empty PATCH body
```

### Step 7: マージ
```
git switch main && git merge feat/05-tests
```

## 4. Git練習ポイント
- `test:` `fix:` のコミットの分離
- コミット前に `go test ./...` が通ることを確認する習慣
- 発展: `git rebase -i` で自分のローカルコミットの順序を整える（**pushしたものには使わない**）

## 5. つまずきやすい点
- テスト関数名は `TestXxx(t *testing.T)`、ファイルは `_test.go`
- サブテストでループ変数を使う場合の挙動（Go 1.22で改善。バージョンを確認）
- テスト間でstoreを共有すると影響し合う → テストごとに新規作成
- カバレッジ100%を目指さない。重要な分岐が守られているかが重要

import (

func TestNormalizeTitle(t *testing.T) {
	tests := []struct {
		name    string
		input   string
		want    string
		wantErr bool
	}{
		{"通常", "牛乳を買う", "牛乳を買う", false},
		{"前後の空白は除去", "  牛乳  ", "牛乳", false},
		{"空", "", "", true},
		{"空白のみ", "   ", "", true},
		{"1文字", "a", "a", false},
		{"100文字(日本語)", strings.Repeat("あ", 100), strings.Repeat("あ", 100), false},
		{"101文字(日本語)", strings.Repeat("あ", 101), "", true},
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			got, err := NormalizeTitle(tt.input)
			if (err != nil) != tt.wantErr {
				t.Fatalf("err = %v, wantErr = %v", err, tt.wantErr)
			}
			if got != tt.want {
				t.Errorf("got %q, want %q", got, tt.want)
			}
		})
	}
}

import (

func TestMemory_CreateAndGet(t *testing.T) {
	m := NewMemory()
	ctx := context.Background()

	created, err := m.Create(ctx, "牛乳")
	if err != nil {
		t.Fatal(err)
	}
	got, err := m.Get(ctx, created.ID)
	if err != nil {
		t.Fatal(err)
	}
	if got.Title != "牛乳" || got.Done {
		t.Errorf("unexpected todo: %+v", got)
	}

func TestMemory_ListNewestFirst(t *testing.T) {
	m := NewMemory()
	ctx := context.Background()
	m.Create(ctx, "first")
	m.Create(ctx, "second")

	list, _ := m.List(ctx, "all")
	if len(list) != 2 || list[0].Title != "second" {
		t.Errorf("want newest first, got %+v", list)
	}
}

func TestMemory_NotFound(t *testing.T) {
	m := NewMemory()
	ctx := context.Background()

	if _, err := m.Get(ctx, 999); !errors.Is(err, ErrNotFound) {
		t.Errorf("Get: want ErrNotFound, got %v", err)
	}
	if err := m.Delete(ctx, 999); !errors.Is(err, ErrNotFound) {
		t.Errorf("Delete: want ErrNotFound, got %v", err)
	}
}

func TestMemory_UpdatePartial(t *testing.T) {
	m := NewMemory()
	ctx := context.Background()
	created, _ := m.Create(ctx, "a")

	done := true
	got, err := m.Update(ctx, created.ID, UpdateInput{Done: &done})
	if err != nil {
		t.Fatal(err)
	}
	if !got.Done || got.Title != "a" { // タイトルは変わらない

```go
package handler

import (
	"encoding/json"
	"net/http"
	"net/http/httptest"
	"strings"
	"testing"

	"todoapp/backend/internal/store"
)

// テストごとに新しい store を作り、テスト同士が影響しないようにする
func newMux() *http.ServeMux {
	mux := http.NewServeMux()
	NewTodoHandler(store.NewMemory()).Register(mux)
	return mux
}

func do(mux *http.ServeMux, method, path, body string) *httptest.ResponseRecorder {
	req := httptest.NewRequest(method, path, strings.NewReader(body))
	rec := httptest.NewRecorder()
	mux.ServeHTTP(rec, req)
	return rec
}

func TestCreate(t *testing.T) {
	tests := []struct {
		name string
		body string
		want int
	}{
		{"正常", `{"title":"牛乳"}`, http.StatusCreated},
		{"空タイトル", `{"title":""}`, http.StatusBadRequest},
		{"空白のみ", `{"title":"   "}`, http.StatusBadRequest},
		{"壊れたJSON", `{`, http.StatusBadRequest},
		{"未知のフィールド", `{"title":"a","x":1}`, http.StatusBadRequest},
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			rec := do(newMux(), "POST", "/todos", tt.body)
			if rec.Code != tt.want {
				t.Errorf("status = %d, want %d (body: %s)", rec.Code, tt.want, rec.Body)
			}
		})
	}
}

func TestListEmptyIsArray(t *testing.T) {
	rec := do(newMux(), "GET", "/todos", "")
	if rec.Code != 200 {
		t.Fatalf("status = %d", rec.Code)
	}
	if strings.TrimSpace(rec.Body.String()) != "[]" {
		t.Errorf("want [], got %s", rec.Body)
	}
}

func TestNotFoundAndBadID(t *testing.T) {
	mux := newMux()
	tests := []struct {
		name, method, path, body string
		want                     int
	}{
		{"GET 存在しない", "GET", "/todos/999", "", 404},
		{"PATCH 存在しない", "PATCH", "/todos/999", `{"done":true}`, 404},
		{"DELETE 存在しない", "DELETE", "/todos/999", "", 404},
		{"GET IDが文字列", "GET", "/todos/abc", "", 400},
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			rec := do(mux, tt.method, tt.path, tt.body)
			if rec.Code != tt.want {
				t.Errorf("status = %d, want %d", rec.Code, tt.want)
			}
		})
	}
}

func TestPatchEmptyBody(t *testing.T) {
	mux := newMux()
	do(mux, "POST", "/todos", `{"title":"a"}`)
	rec := do(mux, "PATCH", "/todos/1", `{}`)
	if rec.Code != 400 {
		t.Errorf("status = %d, want 400", rec.Code)
	}
}

func TestFlow(t *testing.T) {
	mux := newMux()
	do(mux, "POST", "/todos", `{"title":"牛乳"}`)

	rec := do(mux, "PATCH", "/todos/1", `{"done":true}`)
	if rec.Code != 200 {
		t.Fatalf("patch status = %d", rec.Code)
	}
	var got struct {
		Done  bool   `json:"done"`
		Title string `json:"title"`
	}
	json.Unmarshal(rec.Body.Bytes(), &got)
	if !got.Done || got.Title != "牛乳" {
		t.Errorf("unexpected: %+v", got)
	}

	if rec := do(mux, "DELETE", "/todos/1", ""); rec.Code != 204 {
		t.Errorf("delete status = %d", rec.Code)
	}
}
```

- `mux.ServeHTTP` … サーバーを起動せずにリクエストを処理させる
